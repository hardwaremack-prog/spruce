# Spruce

A slides and presentation app that runs in the browser. Part of the [Tidy suite](https://github.com/hardwaremack-prog/tidy-suite) with Tidy and Neat.

![Spruce screenshot](<Spruce - screenshot.png>)

## What's in it

- Add text, pictures, shapes and tables, then drag to move and pull the corners to resize
- Color themes, three fonts (cozy serif, clean sans, typewriter) and slide transitions (fade, slide, zoom)
- Speaker notes that only you see while presenting (press **N**)
- **Present** full screen and use the arrow keys to move through slides
- The **Sidekick** panel estimates your talk time, counts the words on each slide, and checks for slides that are too crowded
- Open a Neat document and each heading becomes a slide
- Saves on its own; open, save as (including PowerPoint), print, dark mode
- **My decks** keeps all your presentations in one place

Shortcut: **Ctrl+M** adds a new slide.

## Run it

Download `spruce-standalone.html` and open it in your web browser. No install, no account, nothing to set up.
